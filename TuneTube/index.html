利用条件 プライバシーポリシー YouTube利用規約 Googleプライバシーポリシー

はじめに

このアプリは YouTube API Services を使って，YouTube の動画を探して再生します．

  • 動画の再生には YouTube の公式プレーヤーを使います．広告やプレーヤーの表示は YouTube のものです．
  • 設定や登録チャンネルは，この端末のブラウザ内にだけ保存します．いつでも「設定」からすべて削除できます．

設定を開くにはPINを入力

設定

表示モード
登録チャンネル（ご家族が設定）

チャンネルのURL，@ハンドル，またはチャンネルIDを入力してください．

    表示

    YouTubeのデータにはショートを見分ける項目がないため，3分以下の動画などを長さで判定します．普通の短い動画も非表示になります．また，プレーヤー内に表示されるリンクまでは制限できません．

    ロック

    本人の誤操作で設定が変わるのを防ぐための簡易ロックです．

    APIキー

    この端末のブラウザ内にだけ保存します．Google Cloud 側でHTTPリファラー制限をかけてください．

    ホーム画面に追加する方法

    1. 画面下（iPadは上）の共有ボタン ⬆ を押す
    2. 「ホーム画面に追加」を選ぶ
    3. 右上の「追加」を押す

    ホーム画面から開いたときは，設定（APIキーなど）をもう一度入力する必要がある場合があります．
