TubeTune プライバシーポリシー

最終更新日：2026年10月10日（ハッカソン試作版）

1．YouTube API Services の利用

本アプリは YouTube API Services を使用して，動画の検索・情報の取得・再生を行います．これらの通信には Google のプライバシーポリシーが適用されます．
Google プライバシーポリシー

2．本アプリが保存する情報

本アプリには独自のサーバーがありません．以下の情報は，利用者の端末のブラウザ内（localStorage）にのみ保存され，開発者に送信されることはありません．

情報目的保存期間
APIキー，表示モード，表示設定アプリの動作利用者が削除するまで
登録チャンネル（チャンネルID，名前，アイコンのURL）登録チャンネルの一覧表示名前とアイコンは7日ごとに再取得して更新
検索結果・動画情報の一時キャッシュAPI利用回数の節約最大6時間（最大30件）．期限切れは起動時に削除
受験生モードの視聴時間（日付と秒数のみ）目標時間の表示当日分のみ使用し，翌日以降は上書き
API使用量の目安（回数のみ）使いすぎの防止当日分のみ
設定画面のPIN（ハッシュ値）設定画面のロック利用者が解除するまで
同意の記録同意画面の表示制御利用者が削除するまで

視聴した動画の履歴，検索した言葉の履歴（一時キャッシュを除く），位置情報，連絡先などは保存しません．Googleアカウントへのログインも求めません．

3．第三者への提供

本アプリが保存した情報を，開発者が第三者へ提供・共有することはありません．なお，APIの呼び出しと動画の再生のため，利用者の端末から Google（YouTube）に直接通信が行われます．

4．子ども向け動画とプレーヤー

動画の再生には，YouTube の公式プレーヤーのプライバシー強化モード（youtube-nocookie.com）を使います．本アプリ自体は，広告配信や行動の追跡のためのデータを収集しません．

5．情報の削除

  • アプリの「設定」→「保存データをすべて削除」から，本アプリが保存したすべての情報を，その場で削除できます．
  • ブラウザのサイトデータを削除することでも消去できます．
