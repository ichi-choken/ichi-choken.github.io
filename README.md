# 家計簿サイト（レシートWeb管理）

レシートを撮るだけで，商品ごとに細かく分類・集計してくれる家計簿Webアプリ．

🔗 **Demo**: https://ichi-choken.github.io/kakeibo/

## 特徴

- **レシート画像から自動で商品を認識・分類**
  Gemini APIによる画像解析で，レシートに書かれた商品名から詳細なカテゴリーを自動判定．手入力の手間を大幅に削減．

- **カテゴリーは自由にカスタマイズ可能**
  デフォルトのカテゴリー一覧だけでなく，自分の生活スタイルに合わせて分類項目を追加・編集できる．

- **カテゴリー別の支出統計**
  ドリルダウン形式で，どのカテゴリーに月々いくら使っているかを一目で確認できる．

- **複数プロフィール対応**
  家族や用途ごとに複数ユーザーを切り替えて管理可能．

- **ブラウザだけで完結**
  データはIndexedDBに保存されるため，サーバー不要．データ削除にはWebAuthnによるロックがかかっており，誤操作による消失を防止．

## セットアップ（初回のみ）

インストール不要，ブラウザだけで数分で使い始められる．

1. 下記リンクからGemini APIキーを無料取得（Googleアカウントでログイン→「Create API key」）
   🔗 https://aistudio.google.com/app/api-keys
2. サイトにアクセス
   🔗 https://ichi-choken.github.io/kakeibo/
3. 取得したAPIキーを設定画面に貼り付け&保存
4. これで準備完了．あとはレシートを撮影するだけ

※ APIキーはブラウザ内（IndexedDB）にのみ保存され，外部サーバーには送信されない．

## 使い方

1. サイトにアクセスし，レシートを撮影またはアップロード
2. Gemini APIが商品を自動でカテゴライズ
3. 必要に応じてカテゴリーを手動調整
4. カテゴリー別の支出統計を確認
