# ichi-choken.github.io

GitHub Pages で公開している個人用 Web アプリ置き場です．いずれも単一ページ構成で，データは端末内に保存されます．

## 公開中のもの

### [kakeibo](https://ichi-choken.github.io/kakeibo/) — 家計簿
レシート撮影から支出管理までを 1 画面で行う PWA 風の家計簿アプリ．

- レシート画像を Gemini API で解析し，店舗・日付・商品・金額を自動入力（1枚／複数枚分割に対応）
- 手入力での収支登録，カテゴリの 3 階層管理（大／中／小）と店カテゴリ管理
- カレンダー表示・リスト表示，カテゴリ別／店別の集計（円グラフ・棒グラフ・折れ線）
- 期間指定（月／週／年／カスタム／全期間），割り勘計算
- 複数ユーザー切り替え，JSON でのエクスポート／インポート
- ユーザー削除は生体認証（WebAuthn）またはパスワードでロック
- ダーク／ライト／自動のテーマ切り替え

Gemini API キーは設定画面から登録し，端末内にのみ保存されます．

### [cio-handyfan](https://ichi-choken.github.io/cio-handyfan/) — CIO HandyFan 取扱いメモ
充電スタンド付きハンディファン「CIO HandyFan」の操作方法・使い方を，付属説明書より引きやすい形でまとめた Web マニュアルです．

- 風量切り替えやボタン操作などの基本操作
- 充電（ポゴピン接続・パススルー充電）まわりの扱い方
- 困ったときの確認ポイント
