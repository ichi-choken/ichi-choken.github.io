# ichi-choken.github.io

GitHub Pages で公開している個人用 Web アプリ置き場です．いずれもビルド不要の単一 HTML ファイルで構成し，データは端末内に保存されます．

## 公開中のもの

### [kakeibo](https://ichi-choken.github.io/kakeibo/) — レシート家計簿

レシートを撮るだけで，商品ごとに分類・集計してくれる家計簿アプリです．サーバーを立てずにブラウザだけで完結します．

**主な機能**

- レシート画像を Gemini API で解析し，店舗・日付・商品・金額を自動入力（1枚／複数枚分割に対応）
- カテゴリの3階層管理（大／中／小）と店カテゴリ管理．分類項目は自由に追加・編集できる
- カレンダー表示・リスト表示，カテゴリ別／店別の集計（円グラフ・棒グラフ・折れ線）
- 期間指定（月／週／年／カスタム／全期間），割り勘計算
- 複数ユーザー切り替え，JSON でのエクスポート／インポート
- ユーザー削除は生体認証（WebAuthn）またはパスワードでロック
- ダーク／ライト／自動のテーマ切り替え

**実装のポイント**

- 単一 HTML（約 10,000 行）で完結．外部依存はグラフ描画の Chart.js のみで，ビルド工程もフレームワークも使っていません
- レシート画像は Gemini API（既定は `gemini-2.5-flash`，設定画面でモデル切り替え可）へ直接送信し，カテゴリ定義をプロンプトに自動で埋め込むことで，自分が定義した分類体系に沿った結果を返させています
- 明細は IndexedDB，カテゴリ定義や設定は localStorage に保存．`content://` スキームで localStorage が永続しない環境向けに，設定を IndexedDB へ退避する経路も用意しています
- 削除操作には WebAuthn による確認を挟んでいます．端末を操作できる人が本気で回避すれば突破できる仕組みであり，あくまで誤操作による消失を防ぐためのものです

**使い始めかた**

1. [Google AI Studio](https://aistudio.google.com/app/api-keys) で Gemini API キーを取得
2. [アプリ](https://ichi-choken.github.io/kakeibo/) を開き，設定画面にキーを貼り付けて保存
3. レシートを撮影する

API キーは端末内にのみ保存され，Gemini 以外の外部サーバーへは送信されません．

ライセンスは MIT です．

### [cio-handyfan](https://ichi-choken.github.io/cio-handyfan/) — CIO HandyFan 取扱いメモ

充電スタンド付きハンディファン「CIO HandyFan」の操作方法を，付属説明書より引きやすい形でまとめた Web マニュアルです．

- 風量切り替えやボタン操作などの基本操作
- 充電（ポゴピン接続・パススルー充電）まわりの扱い方
- 困ったときの確認ポイント

## 構成

| | 内容 |
|---|---|
| 形式 | 単一 HTML ファイル（ビルド不要） |
| 外部ライブラリ | Chart.js 4.4.1（CDN） |
| 外部 API | Gemini API（画像解析） |
| データ保存 | IndexedDB／localStorage |
| 認証 | WebAuthn（削除操作のロック） |
| ホスティング | GitHub Pages |
