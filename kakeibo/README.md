# 家計簿サイト（レシートWeb管理）

レシートを撮るだけで，商品ごとに細かく分類・集計してくれる家計簿 Web アプリ．サーバーを立てずにブラウザだけで完結します．

🔗 **Demo**: https://ichi-choken.github.io/kakeibo/

## 特徴

- **レシート画像から自動で商品を認識・分類**
  Gemini API による画像解析で，レシートに書かれた商品名から詳細なカテゴリを自動判定．店舗・日付・金額まで自動入力され，手入力の手間を大幅に削減します．1枚のレシートでも，複数枚をまとめて撮った画像の分割にも対応．

- **カテゴリは3階層で自由にカスタマイズ**
  大／中／小の3階層で管理し，自分の生活スタイルに合わせて分類項目を追加・編集できます．店カテゴリはレシート保存時に自動登録されます．

- **カテゴリ別・店別の支出統計**
  ドリルダウン形式で，どのカテゴリに月々いくら使っているかを確認できます．円グラフ・棒グラフ・折れ線で表示し，期間は月／週／年／カスタム／全期間から選べます．割り勘計算にも対応．

- **複数プロフィール対応**
  家族や用途ごとに複数ユーザーを切り替えて管理できます．

- **ブラウザだけで完結**
  サーバー不要で，データは端末内に保存されます．JSON でのエクスポート／インポートによるバックアップに対応．

## 実装のポイント

- **単一 HTML（約 10,000 行）で完結．** 外部依存はグラフ描画の Chart.js のみで，ビルド工程もフレームワークも使っていません．GitHub Pages に置くだけで動きます．

- **カテゴリ定義をプロンプトに自動で埋め込む．** Gemini に画像を投げる際，ユーザーが定義した分類体系をプロンプトへ差し込むことで，汎用的なカテゴリではなく自分の分類に沿った結果を返させています．コンビニや外食といった店舗タイプ系のカテゴリは，店名から自動判定します．

- **保存先を用途で分けている．** 明細は IndexedDB，カテゴリ定義や設定・API キーは localStorage に保存．`content://` スキームで localStorage が永続しない環境向けに，設定を IndexedDB へ退避する経路も用意しています．

- **削除操作に確認を挟む．** ユーザー削除には WebAuthn による生体認証，またはパスワードによるロックをかけられます．端末を操作できる人が本気で回避すれば突破できる仕組みであり，誤操作による消失を防ぐためのものです．

## セットアップ（初回のみ）

インストール不要，ブラウザだけで数分で使い始められます．

1. 下記リンクから Gemini API キーを無料取得（Google アカウントでログイン →「Create API key」）
   🔗 https://aistudio.google.com/app/api-keys
2. サイトにアクセス
   🔗 https://ichi-choken.github.io/kakeibo/
3. 取得した API キーを設定画面に貼り付けて保存
4. これで準備完了．あとはレシートを撮影するだけ

※ API キーは端末内にのみ保存され，Gemini API 以外の外部サーバーへは送信されません．

## 使い方

1. サイトにアクセスし，レシートを撮影またはアップロード
2. Gemini API が商品を自動でカテゴライズ
3. 必要に応じてカテゴリを手動調整
4. カテゴリ別の支出統計を確認

## 使用技術

| | 内容 |
|---|---|
| 形式 | 単一 HTML ファイル（ビルド不要） |
| 外部ライブラリ | Chart.js 4.4.1（CDN） |
| 外部 API | Gemini API（既定は `gemini-2.5-flash`，設定画面でモデル切り替え可） |
| データ保存 | IndexedDB（明細）／ localStorage（設定・カテゴリ定義） |
| 認証 | WebAuthn（削除操作のロック） |
| ホスティング | GitHub Pages |
